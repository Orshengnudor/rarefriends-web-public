# Getting Real: 10 Commandments for an AI Coding Agent

1. **Solve the problem in front of you.**
   Do not add features, options, abstractions, or infrastructure that were not asked for.

2. **Write less code.**
   Use what already exists before adding new helpers, libraries, layers, or systems.

3. **Do not build for hypothetical future needs.**
   Handle the current requirement well. Generalize later when there is evidence you need to.

4. **Get the whole flow working early.**
   Prefer a simple end-to-end implementation over building isolated pieces first.

5. **Prefer obvious code.**
   Avoid cleverness, indirection, and patterns that make the code harder to follow.

6. **Abstract only after repetition is real.**
   A little duplication is better than the wrong abstraction.

7. **Fit the existing codebase.**
   Follow its conventions and use its existing tools unless there is a clear reason not to.

8. **Make it work before refining it.**
   Get the core behavior right first. Then handle edge cases, polish, performance, and cleanup as needed.

9. **Choose and move on.**
   If several options are good enough, pick the simplest one that is easy to change later.

10. **Remove what you no longer need.**
    Delete dead code, temporary workarounds, unused helpers, and unnecessary complexity when you touch them.

## Default rule

**Do the smallest complete thing that solves the problem and is easy to change.**
